## 2. Discovery — musi być krótkie

Na kanale prywatnym (companion / HA):

```text
all discovery
```

**PASS** przykładowa linia:

```text
Heltec_v3a id=XXXXXXXX tag=… fw=… v=1.2 up=… caps=battery,button
```

| Check | PASS | FAIL |
|-------|------|------|
| `id=` długość | dokładnie **8** hex | 64 hex / brak |
| `v=1.2` | tak | `protocol=` / `sdk=` / `protocol_min` |
| `tag=` | tak (bez `profile=` albo tylko legacy) | tylko `profile=` bez `tag=` |
| `up=` | human (`2h33m`, `45s`) | tylko `uptime=9209` |
| `features=` / `transport=` na discover | **brak** | obecne |
| `caps=` | CSV | ucięte / brak przy krótkiej linii |

## 5. `call` (RPC)

Parser-neutral — zwykła komenda.

```text
Heltec_v3a#7 call scene.morning
```

Jeśli host nie obsługuje proc → `#7 err unknown_proc`.

```text
Heltec_v3a call button_pressed
→ err invalid_argument reason=proc
```

(flat name **zakazane**)

```text
ha#7 call button.pressed count=4
```

Gdy HA/host z handlerem:

```text
#7 ok
#7 ok state=closed
#8 err denied reason=acl
```

**FAIL:** `ok button pressed`, `ok scene started`, dowolny prose bez `=`.
